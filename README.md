# 🚀 Mi Portfolio Personal

Bienvenido a mi sitio web personal. Aquí comparto mi trayectoria académica, experiencia laboral y los proyectos en los que he trabajado.

## 🛠️ Tecnologías utilizadas
* **HTML5:** Estructura semántica.
* **CSS3:** Estilos personalizados y Flexbox/Grid para diseño responsivo.
* **SVG:** Iconografía ligera.

## 📱 Características
* **Diseño Responsive:** Adaptado para móviles, tablets y escritorio.
* **Menú Navegable:** Acceso rápido a las diferentes secciones.
